💡 Why GitHub?

Why did I choose GitHub?

เว็บไซต์นี้จัดทำขึ้นโดยใช้ GitHub Pages เพื่อเผยแพร่แฟ้มสะสมงาน (Portfolio) ในรูปแบบออนไลน์


GitHub ช่วยให้สามารถแบ่งปันผลงาน ผ่านลิงก์เว็บไซต์ได้อย่างสะดวก สามารถอัปเดตข้อมูลได้ตลอดเวลา และเข้าถึงได้จากทุกอุปกรณ์


การนำ GitHub มาประยุกต์ใช้กับ Portfolio ทำให้แฟ้มสะสมงานมีความทันสมัย เป็นระเบียบ และง่ายต่อการนำเสนอ
